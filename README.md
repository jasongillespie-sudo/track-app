# Video Timer

An Android app (Samsung and other Android 10+ phones) that records video and runs a stopwatch at the same time.

- **Start/Stop Video**: records video only
- **Start/Stop Timer**: runs the stopwatch only
- **Start Both / Stop Both**: one tap starts both; if anything is running, one tap stops it all
- **Reset**: sets the stopwatch back to zero

Videos are saved to the Gallery in the album **Movies/VideoTimer**.

## Getting the app file (APK)

Every push to GitHub builds the app automatically (see the **Actions** tab).
Open the latest run and download **VideoTimer-apk**. It's a zip file that contains `VideoTimer.apk`.
